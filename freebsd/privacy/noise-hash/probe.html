Canvas noise: which pixels move

This page draws flat colours on canvases, reads them back, and lists the pixels that came back changed. It makes no network request and stores nothing. Serve it over http (for example python3 -m http.server in this directory) and open it as http://localhost:8000/probe.html and as http://127.0.0.1:8000/probe.html, which are two different sites to the browser. Then try a private window and a new profile.
