# Design intake

Work in progress on Beryllium's artwork, kept apart from `artwork/` and
`branding/`, which the build and its tests read. Each round is a dated
folder with its own README: what it contains, how it was made, and what
the owner has to decide. Nothing here reaches the browser until an
approved round is integrated through `branding/tools/` in a separate
change. Licences as for `artwork/` (CC BY 4.0 for artwork, GPL-3.0 for
tools); the name and logo are reserved ([TRADEMARKS.md](../TRADEMARKS.md)).
