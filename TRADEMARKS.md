## Uses that need no permission

- Referring to the project by name, accurately: in articles, reviews,
  documentation, talks, package listings and comparisons.
- Distributing unmodified Beryllium releases, and packages built from them,
  under the Beryllium name and logo, including in operating system package
  collections such as the FreeBSD Ports Collection. Changes needed only to
  build, package or install Beryllium on the target system (paths,
  dependencies, packaging metadata) do not count as modifications; changes
  to what the browser does do.
- Using the logo to link to the project's website or repository.
- Saying, where true, that software is "based on Beryllium" or "compatible
  with Beryllium".

## Uses that need permission

- Distributing a modified browser under the Beryllium name or logo. Give a
  modified version its own name and logo; it may say it is based on
  Beryllium.
- Using the name or logo in the name of another product, service,
  company, domain or account.
- Any use that suggests the Beryllium Browser project made, sponsored or
  approved something it did not.
- Names or logos that could be confused with Beryllium's.

Ask by opening an issue in this repository.
